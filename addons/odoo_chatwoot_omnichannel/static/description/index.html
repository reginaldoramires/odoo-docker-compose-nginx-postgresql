🚀 Odoo Chatwoot Omnichannel Integration

Overview

Complete omnichannel solution integrating Odoo with Chatwoot open-source customer support platform.

Key Features

✅ Multi-Channel Support

  • WhatsApp Business API
  • Facebook Messenger
  • Email (SMTP/IMAP)
  • Website Chat Widget
  • Twitter DM
  • Telegram
  • SMS (Twilio)

🔄 Real-time Synchronization

  • Webhooks for instant updates
  • REST API integration
  • Automatic sync every 5 minutes (configurable)

👥 Contact & Lead Management

  • Automatic partner creation
  • CRM lead generation
  • Complete conversation history

🎯 Advanced Features

  • Agent dashboard
  • Team management
  • Automatic assignment
  • Labels and categorization
  • CSAT surveys
  • Performance metrics

Installation

Important: This module requires Chatwoot to be installed and running. See CHATWOOT_INTEGRATION.md for complete installation guide.
  1. Install Chatwoot using Docker (included in project)
  2. Install this module in Odoo
  3. Configure Chatwoot account in Odoo
  4. Set up webhooks
  5. Start using!

Configuration

After installation:

  1. Go to Chatwoot → Configuration → Accounts
  2. Create new account with your Chatwoot URL and API token
  3. Test connection
  4. Click "Sync All" to import data
